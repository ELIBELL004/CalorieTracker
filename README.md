# CalorieTracker
IT 106 group project: Elias, Junaid, Naureen, Farhan



A Java program that helps a student log the meals they eat in a day while staying within a daily budget and a calorie goal (2,000 calories for women, 2,500 for men). 
If the student goes over the goal, it suggests how many miles to jog to burn off the extra calories.
